# Prompt 03: Generate or improve one section

**Use when:** most of the page is good but one section (hero, features, pricing…) isn't. Regenerating the whole page tends to break the parts that already work.

**Attach:** 1 reference screenshot of a great version of this section, plus a screenshot of your current section.

```text
Improve ONE section of my landing page: the {{SECTION — e.g. features}} section.

Keep everything else unchanged. Follow the existing style spec:
{{STYLE_SPEC}}

Current section code:
{{PASTE CODE}}

Copy for this section (use verbatim):
{{COPY}}

Attached: (1) a reference showing a great {{SECTION}} section, (2) my current version.

What's wrong with mine (from critique):
{{e.g. "three identical cards, no product visuals, weak hierarchy"}}

Rebuild this section so that it:
- applies the reference's principles (layout rhythm, hierarchy, how it shows the product)
  without copying its layout or brand
- uses only the spec's tokens (type scale, colours, spacing, radius)
- shows the product with realistic UI where it helps understanding
- works at 390px wide

Explain the 3 main changes in one line each, then output only the section's code.
```
